# FM Entertainment — Concept Proposal

A bilingual, responsive artist management and booking concept built with React, Vite, Tailwind CSS, Framer Motion and Lucide.

## Run locally

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

The GitHub Actions workflow in `.github/workflows/deploy.yml` builds and deploys the site to GitHub Pages after the repository's Pages source is set to **GitHub Actions**.

## Content notes

Artist names and the Raúl Hernández Jr. / Warner Music México partnership are based on public reporting. Booking contact phone is publicly listed as +1 (562) 367-4785. Representative email addresses and official social URLs were not independently verified, so the booking form opens a prefilled email draft for the visitor to address and send. Editorial photography is loaded from Unsplash; replace with approved artist press images before production.
